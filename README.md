# Study App Design Mockups

Three plain-HTML pages, no build step — open `index.html` and scroll.

- **index.html** — Ten design languages for a study app, rendered as full-screen vignettes of the same screen (flashcard + streak + progress + CTA). Scroll to explore, tap cards to flip.
- **paper-notes.html** — "Looseleaf" design-language spec: serif titles (Fraunces), sans body (Sora), mono labels (Space Mono), squared 3px corners, real paper grain — in three live modes: off-white light, warm-black dark, and blueprint.
- **app.html** — Full Looseleaf app mockup: Today, Practice, Decks, Stats, Exams views with checklists, deadline calendar blocks, session grading (green/red), 14-day chart, and a 10-week consistency heatmap.

Mode tabs live in the top-right of both Looseleaf pages.
